# Smart Sensor Network

> **Discipline:** Computer Science

## 📝 About
An end-to-end IoT monitoring system collecting real-time sensor data, processing via edge nodes, and displaying insights on a centralized dashboard.

## 🛠️ Architecture & Tech Stack
`C++` `ESP32` `MQTT` `Node-RED` `InfluxDB` `Grafana`

## 🚀 Setup Instructions
```bash
1. Flash ESP32 firmware using PlatformIO.
2. Configure MQTT broker credentials.
3. Deploy Node-RED flow.
4. Import Grafana dashboard JSON.
```
